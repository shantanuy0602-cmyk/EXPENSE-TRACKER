# Expense Tracker

A simple Python project for recording and checking daily expenses.

## Features
1. Add expense
2. View all expenses
3. Show total expense
4. Show expense by category
5. Clear all expenses

## Technologies
- Python
- Lists
- Dictionaries
- Functions
- if-else
- for loops
- try-except
- Basic text file handling

## How to Run

Run:

python main.py

The expenses are stored in `expenses.txt`.

## Project Modules
- main.py - starts the program
- menu.py - displays the menu
- expense.py - adds and displays expenses
- report.py - calculates reports
- data.py - saves and reads expense data
